# 后湖小区 · 美食地图

按楼栋浏览的社区美食地图。纯静态页面（HTML + CSS + 原生 JS），无框架、无构建、无后端，数据存在浏览器本地。

主色取自中南大学校徽蓝（`#0057A8`）。

---

## 三个版本

| 版本 | 入口 | 适合 | 编辑权限 |
|---|---|---|---|
| 单机版 | 双击 `index.html` | 自己看，数据存本机 | 无限制 |
| 局域网版 | `node server.js` | 宿舍 / 实验室几台设备共用 | 无限制 |
| 部署版 | `node server-auth.js` | 多人维护的正式站点 | 默认**任何人可编辑**，可选开启登录 |

- 部署版说明（含账号登录、CAS 统一身份认证、Docker/nginx）：[deploy/README.md](deploy/README.md)
- 给使用者看的手册：[使用说明.md](使用说明.md)

## 打开

- **电脑**：双击 `index.html`（数据只存本机浏览器）
- **手机 + 电脑同步**：见下方「多端同步」，用服务打开才有多端效果

## 多端同步

默认双击 `index.html` 时，数据只存在当前浏览器（左下角显示「本机保存」），换设备看不到。
想让手机和电脑共用同一份内容：

1. 在 `houhu-food-map` 目录运行：

   ```bash
   node server.js
   ```

2. 终端会打印两个地址，电脑开 `http://localhost:8080`，手机开打印出来的
   `http://192.168.x.x:8080`（同一 Wi-Fi）；
3. 左下角变成绿点「已同步」后，任何一台设备的修改都会：
   - 自动写入服务器上的 `data.json`（约 0.3 秒防抖）；
   - 通过 SSE 实时推送给其他已打开的页面，对方无需刷新。

- 数据文件：`houhu-food-map/data.json`，备份它即可迁移；
- 端口可用 `PORT=9000 node server.js` 修改；
- 关掉服务再打开页面，会退回「本机保存」，改动仍存在浏览器里，下次连上服务后再同步；
- 服务没有登录和权限控制，**只适合家庭 / 宿舍局域网**，不要暴露到公网。

## 玩法

| 操作 | 说明 |
|---|---|
| 拖动空白处 | 平移地图 |
| 滚轮 / 双指捏合 | 以指针为中心缩放（右下角 ＋/− 也可以） |
| 顶部搜索 | 输入店名、分类或楼栋号，回车 / 点结果直接跳转并打开 |
| 点击商户 | 进入详情页，可编辑名称、分类、图文 |
| 右上「编辑模式」 | 显示每栋的 ＋ 按钮、商户上的红色 × 与拖拽手柄 |
| 编辑模式下拖动商户 | 调整顺序，松手后自动重排 |
| 编辑模式下拖右下角斜纹 | 调整该商户占的空间大小 |
| 商户右上角红色 × | 删除该商户（编辑模式下常显，手机也能点） |
| 详情页「＋ 文字 / ＋ 图片」 | 自由添加段落，图片会自动压缩到 1000px 内 |

## 布局规则

- 两列楼栋，**底端对齐**（1 栋与 2 栋同一排）；23 栋在 22 栋上方，21 栋在 19 栋上方，10 栋在 12 与 8 之间；
- 每栋楼是一个**固定尺寸**的盒子（380 × 120），所有楼栋完全一致，左上角标楼栋号；
- 初始没有任何商户，编辑模式下点 ＋ 自行添加；
- 商户格用 `flex: <权重> 1 74px` + `flex-wrap` + `align-content: stretch`：
  - 不论加多少个，都会自动换行并**撑满**楼栋盒子的高度；
  - 只有 1 家时铺满整格，2 家各占一半，7 家会自动缩小字号；
  - 拖拽调大小改的是 `flex-grow` 权重，所以永远不会出现空隙或重叠。
- 坐标系固定在右下角，只有北（上）和东（右），不随平移缩放变化；
- 小区北侧横贯一条**清水路**，中部是小区内部主路；
- 页面用中南校徽蓝作主色，左上角是校徽标识，背景有一层淡淡的手写标语水印。

## 改数据

- 楼栋位置/尺寸：`app.js` 顶部的 `CFG`（`boxW / boxH / gapY / westX / eastX`）
- 楼栋编号与南北顺序：`WEST`（西侧一列，自上而下）/ `EAST`（东侧一列，自上而下），两列按底端对齐
- 初始商户：`SEED` 默认为空，全部在界面上添加
- 重置：没有一键清空按钮；部署版删掉 `data/map.json` 重启即可清空

数据键名 `houhu.foodmap.v2`，存的是整个 `state`（楼栋 → 商户 → 图文块，图片为 dataURL）。
浏览器本地存储一般 5MB，图片多时可能存不下，此时会提示；可以删掉旧图再存。

## 深链

`index.html#b7-1` 会直接打开 7 栋第 1 家商户，链接可分享；打开详情页时地址栏也会自动更新。

## 调试参数

- `?nosse=1`：不建立实时推送连接（截图、离线调试用）
- `?edit=1`：直接进入编辑模式
- `?touch=1`：在电脑上强制显示触屏按键与横屏引导，方便调试移动端布局

## 已知取舍

- 楼栋位置按你给的方位近似摆放（西列 23→2，东列 21→1，底端对齐），不是精确测绘；
- 免费地图瓦片/真实底图未接入，地图是手绘的示意图（这也是能自由加商户的前提）；
- 同步是「整份文档覆盖」的最后写入优先：两台设备**同时**改同一处时，以最后保存的为准；
  正常的一前一后编辑不会丢数据。
